Encode and decode text, images, and files — standard Base64, Base64URL, hex, and URL encoding.

What is Base64? When do people use it?

Base64 turns binary data (images, files, any bytes) into plain ASCII text using 64 safe characters: A–Z a–z 0–9 + / with = padding at the end.

It is not encryption — anyone can decode it. It is only for transport and storage in text-only places.

Common use cases:

  • Images in HTML/CSS/JSON — data:image/png;base64,... embeds a small image without a separate file.
  • Email attachments — MIME encodes binary as Base64 so mail systems handle it.
  • APIs & JWT — JSON Web Tokens and many APIs send binary or metadata as Base64 (often Base64URL: -_ instead of +/).
  • Config & dev debugging — paste a certificate, hash, or small file as text in a form or log.
  • Data URIs — bundle icons, fonts, or thumbnails inline in code or spreadsheets.

Base64 encoder & decoder — FAQ

Answers for common searches: image to Base64, decode online, data URI, JWT, and more.

How do I convert an image to Base64 online for free?

Switch to Image & file → Base64, drop or browse a PNG, JPG, GIF, WebP, or SVG, then copy the Data URI (for HTML/CSS) or raw Base64 (for APIs). No signup and no upload — encoding runs in your browser.

How do I decode Base64 to text or view a Base64 image?

Paste your string into the input box (plain Base64, Base64URL, or a full data:image/... URI) and click Decode. Text appears in the output panel; image payloads show a preview and a download button.

How do I convert PNG or JPG to a Base64 string for HTML and CSS?

Encode the file on the file tab with Data URI selected. Paste the result into src on an <img> tag or into background-image: url(...) in CSS. Keep icons small — very large data URIs hurt page load.

How do I remove the data:image/png;base64, prefix from a data URI?

Paste the full data URI into the text panel and click Strip data URI prefix. You get raw Base64 only — useful for APIs, databases, or JSON fields that expect the payload without the header.

What is the difference between Base64 and Base64URL?

Standard Base64 uses + and /. Base64URL replaces them with - and _ and often drops = padding — common in JWTs, OAuth tokens, and URL query parameters. Use the Base64URL buttons on this page for either format.

What is a data URI and when should I use one?

A data URI looks like data:image/png;base64,iVBORw0.... The MIME type and encoding are in the prefix; the part after the comma is Base64. Use data URIs for small inline assets (favicons, sprites, email HTML). For large images, host a file and link to it instead.

How do I encode a PDF or other file to Base64?

On the file tab, select any file type (PDF, ZIP, JSON, etc.). Choose raw Base64 for API bodies or Data URI when you need the MIME prefix included. Click Open in text panel to decode or transform further.

How do I convert hex to Base64 (or Base64 to hex)?

Paste hexadecimal bytes (with or without spaces, optional 0x) and use Hex → Base64. For the reverse, decode or paste Base64 and click Base64 → Hex — handy for certificates, firmware, and crypto debugging.

What is the difference between Base64 and URL encoding (percent encoding)?

Base64 represents arbitrary binary data as text. URL encoding (percent encoding) escapes special characters in URLs and form data (e.g. space → %20). They solve different problems; this tool supports both.

Why does my Base64 decode fail or show garbled text?

Common causes: wrong variant (try Base64URL decode), missing padding, line breaks in the string, or decoding binary as UTF-8 text. For images, ensure the payload is valid Base64 and use a data:image/... prefix or let the tool auto-detect. Strip whitespace and try again.

Is Base64 encryption? Can I use it to hide passwords?

No. Base64 is encoding, not encryption — anyone can reverse it. Never use Base64 alone to protect passwords, API keys, or personal data. Use proper encryption and secrets management instead.

Is this online Base64 encoder safe? Are my files uploaded to a server?

No uploads. AtomFable runs entirely in your browser using JavaScript and the FileReader API. Your text and files never leave your device, which makes it suitable for quick local encoding without sending data to third parties.

How do I decode a JWT payload (Base64URL)?

A JWT has three dot-separated parts; the middle segment is Base64URL-encoded JSON. Copy that segment, paste it here, and click Base64URL Decode. Note: this only decodes the payload — it does not verify signatures.

Does Base64 make files larger?

Yes — Base64 expands binary size by roughly 33% because every 3 bytes become 4 ASCII characters. That is normal; use it when you need text-safe transport, not for compressing files.
